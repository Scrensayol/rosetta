every decompiler says it's accurate. rosetta checks.

rosetta compiles a program, hands the bytecode to a decompiler, recompiles what comes back and runs both. if the output doesn't print exactly what the original printed, it's wrong, whatever it looks like.

leaderboard view a result documentation discord 
# build it once
git clone https://github.com/Scrensayol/rosetta
cd rosetta && cargo build --release

# ~810 round trips; --tier full runs ~12,000
./target/release/rosetta bench \
  --decompiler 'mine=/path/to/decompiler {}' \
  --version mine=1.0
the decompiler gets a raw bytecode file as {} and prints the source. drop the json it writes into the result viewer.

what makes rosetta different?

decompilers grade themselves on how the output looks. rosetta grades them on what it does.

leaderboard

official runs of the same suite on the same bytes. wrong output is the number that matters most: a refusal tells you it can't, a wrong answer doesn't.

results you can check

anyone can run the bench and share the json. the viewer tells you what you're looking at.

got a decompiler?

anything that takes a bytecode file and prints source can be benched: a binary, a script, or a web api through a small adapter.
